# tom-homelab (dev)

Generated by Skyforge in **official modules** mode: wherever a service has a mapped official module, the code calls Azure Verified Modules from the public Bicep registry (`br/public:avm/...`), pinned to an exact version. Every other service is written as plain resources in the same package. To get plain resources for the core services instead, set **Code style** to **Plain resources** in the project settings.
